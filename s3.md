# S3

S3 is a public [[service]], a global storage platform, and it's regional based/resilient. By default, the data in a S3 is regional and cannot "leave" that region without custom configurations. The data is replicated accross [[Availability Zone]]s in that region

S3 is perfect for hosting data, large data, and distributed data. It can be accessed via UI, CLI, API, HTTP.

S3 has to main things to deliver:
- **Objects**: the data, it includes **object keys** and **object values**. The **object key** identifies the object in a **bucket**, can consider it likes an file name in a directory. The **object value** is the content of the data. An **object** has: version ID, metadata, access control, subresources. Its size can be from 0 byte to 5 TB.
- **Bucket**: the container of the **objects**, it is identified by name. Bucket names are **globally unique**, and has from 3 to 63 characters length, all lower cases, no underscores, no IP address format. It has a soft limit of 100 buckets, and 1000 hard limit per account. It can contain unlimited objects.
