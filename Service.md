# Service

Public and private services are refering to networking only.

AWS has a private zone called **[[Virtual Private Cloud]] (VPC)**.

There is an AWS Public Zone, it is running between *Internet Zone* and *AWS private zone*.

*On-premises* can access VPCs only if configured via *[[VPN]]* or *[[Direct Connect]]*

*Private services* can be given a public IP 1:1 translated by the **[[IGW]]**
