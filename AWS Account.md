# AWS Account

- An AWS Account is a container for identities and Resources. Identities belongs to [[Identity and Access Management]]
- When creating an AWS Account, you need to provide a credit card and an unique email to create the Root user of that account.
    - An email can only be root account for a specific AWS Account.
